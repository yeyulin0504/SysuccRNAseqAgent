# 连接设置与一键演示配置设计

## 目标

让首次使用者在新建分析页和设置页都能看见并完成服务器、LLM 配置的保存与连通测试；同时提供一套真实远程连接演示配置，用于课堂演示完整交互链路。

## 页面交互

- 新建分析页与设置页均展示“服务器连接”和“大模型连接”区块。
- 每个区块提供“保存配置”和“保存并测试连接”。测试前先保存当前表单。
- 页面显示测试状态、耗时和经过清理的错误摘要；顶部同步显示最近一次连接状态。
- API Key 与服务器密码只写入，不通过读取接口返回明文。
- “加载演示配置并测试”预填 `10.30.24.1:22`、用户 `yeyulin`、Slurm、远程工作目录 `/hwdata/home/yeyulin/`，以及 API Base `https://llmapi.paratera.com/v1`、模型 `Deepseek-V4-Flash`；用户填写 SSH 密码和 API Key 后，保存并真实测试两条链路。
- 模型区提供“拉取模型列表”，携带当前 API Key 请求 OpenAI 兼容 `/models`，成功后以下拉框选择，失败时保留手动输入。

## 样本自动识别

- 远程 FASTQ 路径通过只读 SSH 扫描，按常见 `_R1/_R2`、`_1/_2` 命名配对并生成样本预览；用户确认后再写入项目配置。
- Counts 文件上传后读取表头，第一列视为基因 ID，其余列自动生成样本；分组使用批量粘贴或批量选择，不要求逐个单元格录入。
- 无法配对、重名或无法识别的文件单独列出，必须由用户修正后才能确认计划。

## 后端接口

- 保留 `GET/POST /api/config` 作为配置读取与审计保存入口。
- 新增服务器测试接口，调用现有 `test_server_connection`；本地模式执行只读自检，远程模式执行真实连接探测。
- 新增 LLM 测试接口，向 OpenAI 兼容端点发送最小测试请求。
- 新增模型列表接口，代理访问配置端点的 `/models` 并返回清理后的模型 ID。
- 新增远程目录扫描与 counts 表头解析接口，仅返回结构化样本预览。
- 新增演示配置接口，写入上述远程服务器及 LLM 非秘密字段，不写入密码、API Key 或伪造结果。

## 错误与安全

- 所有连接异常以结构化失败结果返回，页面不崩溃。
- 响应不包含密钥、密码、原始远程输出或完整堆栈。
- 只有真实 SSH/API 请求成功时才显示“已连接”。

## 验收

- 配置保存后刷新页面仍存在，秘密字段只显示“已设置”。
- 服务器和 LLM 测试均有成功与失败测试。
- 填写 SSH 密码和 API Key 后，一键演示配置可保存并执行两项真实连接测试。
- 远程 FASTQ 与 counts 两种入口均能自动产生样本预览。
- 新建分析页能直接进入连接设置，原有 counts 上传与项目流程保持可用。
