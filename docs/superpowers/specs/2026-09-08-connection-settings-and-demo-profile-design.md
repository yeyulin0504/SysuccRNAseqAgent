# 连接设置与一键演示配置设计

## 目标

让首次使用者在新建分析页和设置页都能看见并完成服务器、LLM 配置的保存与连通测试；同时提供不依赖院内服务器或外部 API Key 的一键演示配置，用于课堂演示完整交互链路。

## 页面交互

- 新建分析页与设置页均展示“服务器连接”和“大模型连接”区块。
- 每个区块提供“保存配置”和“保存并测试连接”。测试前先保存当前表单。
- 页面显示测试状态、耗时和经过清理的错误摘要；顶部同步显示最近一次连接状态。
- API Key 与服务器密码只写入，不通过读取接口返回明文。
- “加载演示配置并测试”写入本地执行服务器配置和内置演示模型配置，随后依次测试两条链路。

## 后端接口

- 保留 `GET/POST /api/config` 作为配置读取与审计保存入口。
- 新增服务器测试接口，调用现有 `test_server_connection`；本地模式执行只读自检，远程模式执行真实连接探测。
- 新增 LLM 测试接口，真实模式向 OpenAI 兼容端点发送最小测试请求；演示模式返回固定测试响应并明确标记 `demo`。
- 新增演示配置接口，写入可逆的本地演示配置，不写入伪造的科学结果。

## 错误与安全

- 所有连接异常以结构化失败结果返回，页面不崩溃。
- 响应不包含密钥、密码、原始远程输出或完整堆栈。
- 演示模式只验证产品交互与控制面，不声明已连接真实 HPC 或真实 LLM。

## 验收

- 配置保存后刷新页面仍存在，秘密字段只显示“已设置”。
- 服务器和 LLM 测试均有成功与失败测试。
- 一键演示配置无需外部依赖即可显示两项测试通过。
- 新建分析页能直接进入连接设置，原有 counts 上传与项目流程保持可用。
