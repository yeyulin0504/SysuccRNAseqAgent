SYSU RNA-seq Agent：另一台 Windows 电脑测试说明
================================================

一、测试电脑要求

1. Windows 10 或 Windows 11（64 位）。
2. 已安装 64 位 Python 3.13，并带有 py.exe 启动器。
3. 已连接能访问实验室服务器的内网或 VPN。
4. 本测试包不需要联网下载 Python 包。

二、安装和启动

1. 解压整个 ZIP；不要直接在压缩包内运行。
2. 双击“安装Agent.bat”，等待出现“安装完成”。
3. 双击“启动Agent.bat”。

三、填写服务器

服务器地址：10.30.24.1
用户名：yeyulin
SSH 端口：22

在 GUI 的“服务器”页：

1. 填写上述服务器地址、用户名和端口。
2. “SSH 登录方式”选择 password。
3. 点击“输入临时密码”，输入你自己的服务器密码。
4. 点击“测试连接”。

密码只保存在当前 Agent 进程的内存中，关闭程序后消失，不会写入
project.json、默认配置或日志。不要通过聊天、截图或文件发送密码。

四、首次连接的主机指纹

如果 Agent 提示主机指纹尚未信任，请先打开 PowerShell，运行：

ssh yeyulin@10.30.24.1

核对管理员提供的服务器指纹，确认无误后输入 yes。随后退出 SSH，
重新在 Agent 中点击“测试连接”。

五、建议的测试顺序

1. 先测试 SSH 连接。
2. 确认远程项目根目录和服务器调度器（Slurm/PBS）填写正确。
3. 在“样本”页选择本地 FASTQ 目录，每行填写样本 ID、R1、R2。
4. 点击“仅上传 FASTQ”，核对弹窗中的远程目标目录后确认。
5. 看到“FASTQ 上传完成”后，数据传输测试即通过。
6. 在服务器分析软件和参考索引准备完成前，不要点击
   “仅提交”或“保存并运行”。

注意：“仅上传 FASTQ”只会创建项目的 raw 目录和上传数据，不会
提交任务。同名远程文件会被替换，确认弹窗会在上传前提示。
